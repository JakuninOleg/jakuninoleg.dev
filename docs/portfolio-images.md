## Generation prompts

### go-ai

Use case: photorealistic-natural. Create a 16:10 landscape editorial photograph for a developer portfolio Go-Ai backend LLM gateway project. A real quiet server cabinet closeup, three modest brushed aluminium network appliances with neatly routed muted blue ethernet patch cables, tactile metal, subtle activity LEDs. Restrained technical photography, neutral soft room light, slate blue and graphite, slight authentic wear, natural exposure, clean asymmetric composition readable as a small cover. No people, no logos, no text, no floating interfaces, no holograms, no glowing trails, no sci-fi, no glossy 3D render. The result should feel photographed for an independent engineering magazine.

### lu4-ai

Use case: photorealistic-natural. Create a 16:10 landscape editorial photograph for Lu4-AI, a Python OCR and Arduino HID automation project. Real electronics workbench detail: one small blue Arduino Leonardo style microcontroller board lying flat on a worn dark grey desk mat, USB cable plugged into its actual USB port leading toward a cropped ordinary laptop at the back, corner of a black keyboard at right, simple ambient daylight. Board, solder joints and cable physically believable, restrained composition, shallow but sufficient depth of field, natural imperfect textures, muted blue grey with tiny warm status light. No readable text, no logos, no people, no floating UI, no glowing data streams, no futuristic holograms, no stylized 3D render.
